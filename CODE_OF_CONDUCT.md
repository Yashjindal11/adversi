# Code of Conduct

AdverSI adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique ideas rather than people, and keep
discussions focused on the work. Adversarial reasoning is the project's subject, not a
style of interaction.

Harassment, personal attacks, discriminatory language and publishing others' private
information are not acceptable in any project space.

Report concerns privately to the maintainer via a
[GitHub security advisory](https://github.com/Yashjindal11/adversi/security/advisories/new)
(select "report a vulnerability" and note that it is a conduct report) or by email listed
on the maintainer's GitHub profile. Reports are handled confidentially. The maintainer
may remove content, warn, or ban participants as described in the Covenant's enforcement
guidelines.
