## Mark

Two chevrons press toward a single point from opposite sides: independent perspectives
in opposition, converging on something that survives scrutiny. The point is small and
teal: what remains after challenge is usually modest, and it is *verified*.

- Left chevron, indigo `#818CF8`: one line of reasoning
- Right chevron, amber `#F59E0B`: the challenge
- Centre point, teal `#2DD4BF`: the verified conclusion
- Field, ink `#16142B`

No robots, brains or glowing networks.

## Palette

| Role | Hex | Use |
|---|---|---|
| Ink | `#16142B` | Text, mark background, header |
| Indigo | `#4F46E5` | Primary actions, proponent, links |
| Amber | `#D97706` | Challenges, uncertainty, skeptic |
| Teal | `#0D9488` | Verified evidence, supported claims |
| Red | `#DC2626` | Contradicted claims, contradicting evidence |
| Muted | `#6B6889` | Secondary text |

Status colours are semantic and consistent across the UI and HTML reports: teal =
supported, amber = uncertain, red = contradicted, grey = unverified.

## Name and voice

- Written **AdverSI** (capital S and I). "Adversarial Super Intelligence" is the long
  form; it names an aspiration, not a capability claim.
- Tagline: *Make intelligent systems challenge their own reasoning.*
- Positioning line: *Independent reasoning. Adversarial critique. Evidence. Synthesis.*
- Voice: precise and plain. Say what the system does and how it can be checked. Avoid
  "knows", "truth", "superhuman", "hallucination-free".
